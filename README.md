## Wrap

[![test](https://github.com/ezhuk/wrap/actions/workflows/test.yml/badge.svg)](https://github.com/ezhuk/wrap/actions/workflows/test.yml)

A lightweight, high-performance C++ framework for building HTTP APIs.

> [!NOTE]
> Wrap is under active development and is not yet ready for production use.

## Getting Started

Check out and run the included example as follows:

```bash
bazel run -c opt //examples/hello
```
